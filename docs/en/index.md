# Feather Documentation

Feather is a desktop application for Windows. It manages local services such as MariaDB, Nginx and Apache, provides a terminal, file management and an SQL client for remote servers, and can be extended with plugins.

This documentation applies to version 1.0.

The user documentation is currently available in German only: [Anwenderdokumentation](../index.md). The developer documentation is available in English below.
